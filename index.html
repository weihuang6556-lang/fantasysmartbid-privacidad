Política de Privacidad

Última actualización: 14 de septiembre de 2026

Esta Política de Privacidad describe cómo la aplicación FantasySmartBid (en adelante, "la aplicación") trata los datos de sus usuarios. Al instalar y usar la aplicación, aceptas las prácticas descritas en esta política.

1. Responsable

La aplicación es desarrollada y gestionada por su desarrollador. Para cualquier consulta sobre esta política o sobre tus datos, puedes contactar en: weihuang6556@gmail.com.

2. Datos que recopila la aplicación

La aplicación no recopila ni transmite datos personales a servidores propios. Todos los datos que gestiona se almacenan exclusivamente en tu dispositivo.

Concretamente, la aplicación puede almacenar de forma local:

  • Credenciales y token de sesión de tu cuenta de Biwenger, necesarios para iniciar sesión y ejecutar las pujas programadas. Se guardan cifrados mediante el almacenamiento seguro del sistema operativo.
  • Datos de tu cuenta (identificador de usuario y de liga).
  • Pujas programadas, horarios y preferencias de configuración.
  • Registros internos (logs) para el diagnóstico de errores, que solo puedes consultar tú desde la propia aplicación.

3. Cómo usamos tus datos

  • La aplicación se conecta a la plataforma Biwenger usando tus propias credenciales para leer y realizar pujas en tu equipo de fantasía.
  • Programa notificaciones y alarmas locales para avisarte y ejecutar tu puja en el momento que configures.
  • Los datos se usan únicamente para ofrecer la funcionalidad descrita. No se utilizan para publicidad, no se analizan de forma externa y no se comparten con terceros.

4. Almacenamiento y seguridad

Tu token de sesión, email e identificadores se guardan cifrados en el almacenamiento seguro del dispositivo (Android Keystore / almacenamiento cifrado). El resto de datos de configuración se guarda en bases de datos locales de la aplicación. No se envían a ningún servidor.

No podemos garantizar la seguridad absoluta de ningún sistema, pero aplicamos las medidas técnicas razonables para proteger tu información mientras esté en tu dispositivo.

5. Servicios de terceros

La aplicación permite la autenticación e interacción con la plataforma Biwenger (biwenger.as.com). Los datos que facilites directamente a Biwenger se rigen por la política de privacidad y los términos de servicio de Biwenger, no por esta política.

6. Permisos de la aplicación

La aplicación solicita los siguientes permisos de Android, utilizados para el correcto funcionamiento:

  • Internet: para conectarte a Biwenger.
  • Notificaciones / Alarmas exactas / Ignorar optimización de batería: para notificarte y ejecutar las pujas programadas a la hora exacta.
  • Reinicio del sistema: para reprogramar las pujas pendientes tras reiniciar el dispositivo.

7. Menores

La aplicación no está dirigida a menores de 13 años y no recopila intencionadamente datos de menores.

8. Eliminación de tus datos

Para eliminar todos los datos locales almacenados, puedes desinstalar la aplicación o usar la opción de "cerrar sesión / borrar datos" dentro de la aplicación. Los datos almacenados en tu dispositivo se eliminarán.

9. Cambios en esta política

Podemos actualizar esta política de privacidad. Cualquier cambio se publicará en esta página con una nueva fecha de actualización.

10. Contacto

Si tienes preguntas sobre esta política de privacidad, escribe a: weihuang6556@gmail.com.
